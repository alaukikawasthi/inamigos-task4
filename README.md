# InAmigos Foundation — Internship Task 4

A single-page interactive website prototype based on the NGO Website Feature Highlight assignment.

## Included features
- Donate & Support
- Volunteer With Us (working demo modal form)
- Our Impact with count-up animation
- Campaigns & Initiatives
- Testimonials & Stories
- Design Objective
- Responsive mobile navigation
- Smooth scrolling and interactive campaign messages

## Important
The volunteer form is a front-end demo only; it does not send data to a server.

The impact figures are presented from information published on the InAmigos Foundation website/publications. Before final submission, re-check the foundation's current figures if your internship requires the latest numbers.

## Run
Open `index.html` in a browser. No installation is required.

For GitHub Pages, upload the whole folder while preserving the `assets` folder.
